# 🍳 SavoryStudio - Gourmet Recipe Management Platform

**SavoryStudio** is a modern, responsive web application built with **Laravel 11**, **Inertia.js**, and **React**. Designed with an elegant, user-friendly culinary theme, it allows users to explore, search, and manage a curated catalog of authentic Filipino food recipes with interactive ingredient checklists and step-by-step cooking guides.

---

## ✨ Features

- 🔐 **Authentication Guard:** Restricts full recipe viewing (ingredients & cooking guides) to registered and logged-in users.
- 🍲 **Curated Recipe Catalog:** Includes popular Filipino dishes such as Classic Chicken Adobo, Authentic Beef Kare-Kare, Sour Pork Sinigang, Crispy Pork Sisig, Spicy Bicol Express, and more.
- 🔍 **Real-Time Recipe Search:** Search recipes instantly by title or description.
- 🏷️ **Category Filtering:** Quickly filter recipes by category (*Chicken*, *Pork*, *Beef*, *Soup*, or *All*).
- 🛒 **Interactive Ingredient Checklist:** Check off ingredients dynamically as you shop or cook.
- 📱 **Fully Responsive UI:** Built with Tailwind CSS, supporting mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Backend:** Laravel Framework (PHP)
- **Frontend:** React with Inertia.js
- **Styling:** Tailwind CSS & Custom Glassmorphism UI
- **Database:** MySQL
- **Build Tool:** Vite

## 🚀 Getting Started

Follow these steps to set up and run SavoryStudio locally on your machine.

### Prerequisites

Ensure you have the following installed:
- [PHP](https://www.php.net/) (v8.2 or higher)
- [Composer](https://getcomposer.org/)
- [Node.js](https://nodejs.org/) & `npm`
- [MySQL Database Server](https://www.mysql.com/) (e.g., via WampServer or XAMPP)
